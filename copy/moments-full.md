## 一句话定位

移动端聊天式 Web UI，通过 Claude Agent SDK 驱动你本机（或你服务器上）已登录的 **Claude Code CLI**。不打包 Claude，不另起一套 agent；与 CLI 共用配置、权限与会话 transcript——手机上用的，就是你那一套 Claude Code。

**解决的问题：Claude Code 在跑，人却不总在电脑前。**
