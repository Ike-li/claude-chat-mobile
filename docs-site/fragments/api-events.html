受控 HTTP 运维端点

端点路径请求方法鉴权与功能说明
/healthGET过鉴权（令牌，或公网 Host 上的 Access JWT），输出服务健康状况 JSON；含 versions.server 与运行态
/metricsGET过鉴权；进程内计数的 JSON 快照，不是 Prometheus 文本，重启清零
/push/vapid-public-keyGET过鉴权；推送未配置时返回 503
/push/subscribePOST过鉴权，且设备须已被信任（或属于 Access 已验 / 真本机直连这类免审批连接）；保存这台设备的推送订阅
/push/unsubscribePOST与订阅同一道设备判据；只摘掉请求里点名的那一条 endpoint，不清空全表
