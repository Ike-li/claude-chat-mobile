封面与导读

Claude Chat Mobile 项目全景手册：认识项目、阅读路线与事实基线。

手册 v2.1 更新于 2026-09-24 · 源码基线 dev@3f488861 · 维护者 Ike-li

Claude Chat Mobile 是一层默认上锁的桥接转发层：把你本机的 claude CLI 接到手机浏览器。同一会话、同一份 transcript、同样的权限与配置。

定位

终端等价入口

不是远程桌面，也不是 Claude 的重新实现。坐在电脑前对终端打字，和在手机上打字效果等价。

形态

自托管桥 (n=1)

Node ≥20 · ESM · Express 5 · Socket.IO 4 · Agent SDK 驱动本机 CLI。坚守单用户自托管立场。

手册

按认知顺序

认识 → 演进 → 方法论 → 实现 → 数据 → 运维 → 规范。以 dev 代码与最新门禁体系为事实基线。

这本手册从哪来

源码分支为 dev（当前基线 HEAD 3f488861；最新发布版为 v1.12.1，dev 上尚未发版的改动在各页单独标注）。仓库以 docs/hard-rules.md（产品边界、n=1 取舍、架构不变量、已决不做）与 docs/architecture.md 为治理依据，本手册按真实运行代码与架构契约重述，不照搬历史陈旧文档。

事实基线约定手册关键数字、协议契约与模块边界以当前 dev 代码为准。若代码演进后行为与手册发生漂移，以生产代码及 tests/gates/ 门禁为准，并应在漂移清单中透明登记。
范围本手册描述产品源码（dev 分支），产物部署于 gh-pages 分支的 docs-site/ 目录，与展示站点统一维护。

三条阅读路线

主线

完整通读 · 约 2–3 小时

从起点到规范，按认知层次逐章顺读。适合准备深入二次开发、维护或接手仓库的人。

速览

30 分钟速读

封面 → 总览 → 架构 → 职责边界 → 终端等价 → 安全模型 → 快速开始 → 漂移清单。详见阅读顺序指南。

角色

按关注面切入

运维部署直奔第六部分；同步与通信查「单驾驶员」与「事件信封」；鉴权安全查第四部分鉴权页。
