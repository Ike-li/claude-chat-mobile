#   · 训练爬虫名单：2026-11-03 Cloudflare 生成的那份去掉 Baiduspider，其余原样保留
#   · PetalBot（华为 Petal 搜索的爬虫）仍然禁止：Cloudflare 在边缘把它归为 AI Crawler，
#     按训练类直接拦截，这里放行它也抓不到。要放它，得先改 Cloudflare 的训练类策略

#     写给守规矩的爬虫看的声明
#   · 不想被收录的页面各自带 <meta name="robots" content="noindex">（目前只有
#     404.html），不靠这里的 Disallow
#   · Bing / Yandex / Seznam 另走 IndexNow 推送（见 _build/submit-indexnow.mjs）
#
# 站点 2026-10-27 起挂在自定义域名的根上，这份文件从那时起才被爬虫读到（RFC 9309 只认
